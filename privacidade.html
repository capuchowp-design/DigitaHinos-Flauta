Política de Privacidade — Flute Bounce

Última atualização: 20 de outubro de 2026 · English version below

Resumo

O Flute Bounce não vende nem compartilha dados pessoais. Não há cadastro, login, anúncios, rastreadores nem ferramentas de análise. Quem usa o app de graça não envia nada. A única exceção é o modo Pro opcional, descrito abaixo.

O que o app faz com seus dados

  • Arquivos MIDI: quando você escolhe um arquivo, ele é lido apenas no seu aparelho para mostrar a flauta tocando. O arquivo não é enviado para lugar nenhum.
  • Composições: as notas que você cria ficam apenas na memória do app no seu aparelho.
  • Preferências: tema claro/escuro e tipo de flauta são guardados localmente no aparelho. Você pode apagá-los limpando os dados do app nas configurações do Android.
  • Exportar MIDI: ao exportar, o app abre o menu "Compartilhar" do Android. Você decide para onde o arquivo vai (por exemplo, Arquivos ou outro app). O Flute Bounce não envia o arquivo por conta própria.
  • Som: as gravações de flauta e as bibliotecas usadas estão dentro do próprio app; ele funciona sem internet.

Permissões

O app não pede acesso a contatos, localização, câmera, microfone, fotos ou armazenamento. O app usa a permissão de "Internet" apenas para o modo Pro opcional (ativar e verificar o código). Sem o modo Pro, o Flute Bounce não usa a rede para enviar ou receber dados.

Modo Pro (opcional)

O app tem um modo Pro opcional, que libera todos os hinos completos. Quem não usa o modo Pro não envia nada. Se você comprar o modo Pro, ao digitar o código recebido o app envia ao servidor de ativação (uma planilha do Google Planilhas e um script do Google Apps Script, controlados pelo desenvolvedor) o código digitado e um identificador técnico do seu aparelho (no Android, o identificador do aparelho gerado pelo sistema; no navegador, uma assinatura calculada a partir de características do aparelho, como tela, fuso horário e idioma). Esse identificador não contém seu nome, e-mail, telefone ou localização. Também ficam registrados na planilha o nome do app, a data e a hora da ativação e das verificações, e quantas vezes o código foi tentado em outro aparelho.

Isso serve apenas para garantir que cada código seja usado em um único aparelho, restaurar seu acesso se você reinstalar o app e bloquear códigos em caso de estorno ou fraude. Depois de ativado, o app consulta o servidor cerca de uma vez por dia; sem internet, o acesso continua liberado. Esses dados ficam na conta Google que administra a planilha, sujeitos à política de privacidade do Google, e não são vendidos nem usados para publicidade.

O pagamento é feito por Pix, diretamente ao desenvolvedor e fora do app: o app apenas gera o código Pix e a chave para você copiar, e não processa pagamentos nem recebe dados financeiros. O comprovante é enviado por você mesmo, pelo WhatsApp, caso use o botão do app; nesse caso, o contato segue as regras do WhatsApp. O comprovante e o número são usados apenas para liberar o código e dar suporte.

Apoio voluntário

O app também pode exibir uma chave de transferência para quem quiser apoiar o projeto por vontade própria. A chave apenas é copiada para a área de transferência quando você toca no botão.

Crianças

O app não coleta dados de ninguém, inclusive de crianças.

Alterações nesta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data atualizada.

Privacy Policy — Flute Bounce

Last updated: October 20, 2026

Summary

Flute Bounce does not sell or share personal data. There is no sign-up, login, ads, trackers, or analytics. Free users send nothing. The only exception is the optional Pro mode, described below.

What the app does with your data

  • MIDI files: a file you choose is read only on your device to animate the flute. It is not uploaded anywhere.
  • Compositions: notes you create stay only in the app's memory on your device.
  • Preferences: light/dark theme and flute type are stored locally on your device. You can erase them by clearing the app data in Android settings.
  • Exporting MIDI: when you export, the app opens Android's "Share" menu. You choose where the file goes. Flute Bounce never sends the file on its own.
  • Sound: the flute recordings and libraries are bundled inside the app; it works offline.

Permissions

The app does not request access to contacts, location, camera, microphone, photos, or storage. The app uses the "Internet" permission only for the optional Pro mode (activating and checking the code). Without Pro mode, Flute Bounce does not use the network to send or receive data.

Pro mode (optional)

The app has an optional Pro mode that unlocks all hymns in full. Users who do not use Pro send nothing. If you buy Pro, when you type the code you received the app sends the activation server (a Google Sheets spreadsheet and a Google Apps Script controlled by the developer) the code you typed and a technical device identifier (on Android, the system-generated device ID; in the browser, a signature computed from device characteristics such as screen, time zone and language). This identifier does not contain your name, email, phone number or location. The spreadsheet also records the app name, the date and time of activation and checks, and how many times the code was tried on another device.

This is only used to make sure each code works on a single device, to restore your access if you reinstall the app, and to block codes in case of refund or fraud. Once activated, the app checks the server about once a day; offline, access stays unlocked. This data is kept in the Google account that manages the spreadsheet, subject to Google's privacy policy, and is not sold or used for advertising.

Payment is made by Pix directly to the developer, outside the app: the app only generates the Pix code and key for you to copy, and does not process payments or receive financial data. You send the receipt yourself via WhatsApp if you use the app's button, in which case WhatsApp's rules apply. The receipt and phone number are used only to release the code and provide support.

Voluntary support

The app may also show a transfer key for people who wish to support the project voluntarily. The key is only copied to the clipboard when you tap the button.

Children

The app does not collect data from anyone, including children.

Changes to this policy

If this policy changes, the new version will be posted on this page with an updated date.
